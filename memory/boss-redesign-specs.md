# Boss 弹幕与炮口设计规范

## Boss 弹幕与炮口设计规范

### 巨兽坦克 (Behemoth)
- 炮口：中央主炮×1（大口径）+ 左右副炮×2（稍小）
- 弹幕范围：正面 120° 扇面
- 主炮：大弹丸扇面散射
- 副炮：辅助弹幕覆盖侧前方

### 幻影坦克 (Phantom)
- 弹幕：多方向单发，多个小型发射口
- 折跃/分身提前提示：在Boss折跃和镜像分身出现前，在地面显示目标位置标记（闪烁光圈/残影），给玩家反应时间
- P1 折跃猎杀：传送前在目的地显示相位标记
- P2 镜像歼灭：分身出现前在对应位置显示镜像残影

### 要塞坦克 (Fortress)
- 本体基本固定（speed 0.08），多炮塔齐射
- 新增2-3个浮游护盾卫星环绕旋转，每个独立HP（40-60）
- 卫星可挡子弹，打掉后不恢复
- P2可刷新一波新卫星或卫星爆炸时释放小型弹幕
- 外观：六边形浮游盾板，绕要塞旋转

### 虚空坦克 (Void)
- P1 引力洪流：单一定向炮管正面扇形射出
- P2 黑洞撕裂：从中心引力核心（亮紫色漩涡）360°向四周爆发，不经过炮管
- 外观：中心显著发光奇点 + 一个小型定向炮管 + 多层吸积环
- 逻辑：定向攻击走炮管，全屏爆发走核心，互不矛盾

### 风暴坦克 (Storm)
- 取消传统炮管，电弧从两个特斯拉线圈顶端直接射出
- P1 电弧狩猎：线圈间产生电弧链，向玩家方向释放
- P2 雷霆天幕：从天空标记位置降下落雷
- 外观：无炮管，双线圈+电弧纹路+球形闪电

### 观星者坦克 (Observer)
- 设计：移动观测平台，非传统坦克
- 无炮管，改为大型旋转雷达/扫描碟盘 + 天线阵列 + 激光指示器
- P1 扫描标记：碟盘发射扇形扫描波束，被扫到的玩家被标记
- P2 轨道审判：碟盘竖起朝上→瞄准激光→从天降光束轰炸
- 配色：白蓝（observatory阵营），流线型平台

### 废铁巨像 (Scrap Colossus)
- 不对称外观：左边巨型废铁拳/链球，右边拼装炮管
- 补丁、焊缝、不同颜色装甲板拼接痕迹
- P1：正面散射废铁碎片（不规则扇形）
- P2：链球砸地+弹片飞溅
- 配色：锈红+铁灰+暗橙

### 雷霆执政官 (Thunder Archon)
- 浮空型，不贴地，速度0.75-0.8（最快Boss）
- 对称设计，背后雷电羽翼（电弧翅膀），头顶光环旋转
- 弹幕从光环/羽翼射出，无传统炮管
- P1 雷电裁决：羽翼展开，扇形电弧扫射
- P2 天罚：光环升起，全场随机落雷+追踪闪电球
- 配色：金+白+电蓝，神圣威严

## 新增 Boss 创意（待实现）

### 轨道炮台 (Orbital Cannon) — moon_arsenal
- 超远程狙击型，固定在远处
- P1 锁定射击：瞄准激光 1.5s 预警 → 高速 railgun 贯穿弹
- P2 扫射阵：多道光束横向扫过战场，Boss 露出散热弱点
- 外观：巨型炮管 + 激光指示器 + 散热片

### 圣龛守卫 (Sanctum Guard) — ash_church
- 神圣堡垒型，自带回复光环 + 周期性无敌
- P1 圣光弹幕：从光环向四周发射慢速金色光弹（规律密集可读）
- P2 护盾转击：反弹子弹 + 无敌间隙自愈加速（输出窗口）
- 外观：教堂彩窗装甲 + 光环 + 浮游圣徽

### 星象仪 (Astrolabe) — observatory
- P1 星轨环：3 层同心圆弹丸不同方向旋转（齿轮咬合），找空隙
- P2 星座阵列：弹幕排列成十字/三角/六边形几何图形，逐组推进
- 外观：旋转天体仪结构 + 星图投影

### 缝合巨兽 (Patchwork Behemoth) — graveyard
- P1 碎片雨：不规则碎片散射（复用 salvage_swarm）
- P2 吞噬爆发：吸收尸体后大范围冲击波 + 弹片环形扩散
- 外观：不同坦克部件缝合的怪物

### 双子坦克 (Gemini Tanks) — void_cult
- 两体同时出场，镜像外观（一明一暗）
- P1 交叉火力：两体向对方射击，弹丸在中间碰撞形成弹幕花
- P2 一体死后另一体狂暴：弹幕密度×3 + 新增追踪弹
- 外观：两台镜像配色坦克（明=亮紫 / 暗=深紫黑）

### 迅影 (Swift Shadow) — storm_cloister
- 最小体积 Boss（36px），速度最快（0.9+）
- P1 手里剑散射：扇形三发 + 烟雾弹隐身 + 残影分身迷惑
- P2 瞬杀连舞：连续 3 次瞬移背刺 + 每次瞬移后 360° 手里剑环
- 外观：暗蓝流线型 + 青色光纹

### 圣龛织者 (Sanctum Weaver) — ash_church
- 完全无攻击性，纯召唤型
- P1 织网召唤：每次召唤 3-5 个精英护卫，小兵全灭后 4 秒脆弱期（承伤×2）
- P2 加速编织：召唤间隔减半 + 小兵附加追踪弹
- 体积 56px（最大），外观：织布机/织网造型

### 灰域剑圣 (Ash Blade) — moon_arsenal
- 近战专属，无炮管，车体前方能量巨刃
- P1 剑术三式：120°扇形横扫 + 直线突进冲刺 + 路径燃烧带残留
- P2 终焉剑舞：冲刺后 360°旋转斩 + 3 圈环形能量波扩散
- 体积 48px，速度 0.7，深红+金边武士造型

### 陷阱师 (Trapper) — graveyard
- 不直接攻击，大范围布置陷阱阵
- P1 地雷/减速带/弹射器，把战场变成迷宫
- P2 陷阱密度翻倍 + 新增追踪雷（缓慢追踪玩家）
- P2 添加少量低速干扰弹幕

### 镜像体 (Mirror Shell) — void_cult
- 复制玩家当前武器的弹幕模式，反过来打你
- P1 完美镜像：弹幕形状/速度/数量完全复制玩家
- P2 强化镜像：弹幕速度+20% + 弹丸尺寸增大
- 换坦克→镜像体也换弹幕

### 沙暴 (Sandstorm) — graveyard
- P1 沙尘帷幕：降低可见度 + 从尘中随机方向突刺弹幕
- P2 沙虫肆虐：沙尘扩大 + 地面出现沙虫突刺预警圈 + 圈内弹幕喷发
- 外观：旋转沙尘团包围的车体

### 重力锚 (Gravity Anchor) — moon_arsenal
- P1 键位反转：周期性反转方向键（上⇔下/左⇔右）3 秒 + 慢速引力弹幕
- P2 引力牢笼：反转间隔缩短至 2 秒 + 持续将玩家拉向 Boss
- 外观：巨型电磁线圈 + 锚形底盘

### 多头蛇 (Hydra) — void_cult
- P1 蛇形弹幕：弹丸按正弦波轨迹射出（蛇形曲线）
- P2 分裂：HP 50% 时分裂成 3 个小体，各自独立战斗，速度更快
- 小体用简化版蛇形弹幕
- 外观：紫色蛇形多节结构

## 炮台转速差异化（全体坦克）

| 阵营/类型 | 转速 | 说明 |
|-----------|------|------|
| observatory（观星台）| 最快 | 精准扫描，炮台如激光瞄准 |
| storm_cloister（雷霆修会）| 快 | 电击反应快 |
| void_cult（虚空教派）| 中快 | 不太靠物理 |
| moon_arsenal（月面兵工厂）| 中 | 标准军事 |
| ash_church（灰域教会）| 慢 | 重甲信仰型 |
| graveyard（残骸群）| 最慢 | 废铁拼装，转不动 |

玩家坦克也按类型差异化转速，狙击最快、广域最慢。

### 玩家坦克转速（按机型）
| 机型 | 转速 |
|------|------|
| 狙击、红枪 | 最快 |
| 追踪、星仪 | 快 |
| 集中、斩魂 | 中快 |
| 扩散、爆裂 | 中 |
| 广域、境界 | 慢 |
