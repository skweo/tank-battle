# Boss 弹幕与炮口设计规范

## Boss 弹幕与炮口设计规范

### 巨兽坦克 (Behemoth)
- 炮口：中央主炮×1（大口径）+ 左右副炮×2（稍小）
- 弹幕范围：正面 120° 扇面
- 主炮：大弹丸扇面散射
- 副炮：辅助弹幕覆盖侧前方

### 幻影坦克 (Phantom)
- 弹幕：多方向单发，多个小型发射口
- 折跃/分身提前提示：在Boss折跃和镜像分身出现前，在地面显示目标位置标记（闪烁光圈/残影），给玩家反应时间
- P1 折跃猎杀：传送前在目的地显示相位标记
- P2 镜像歼灭：分身出现前在对应位置显示镜像残影

### 要塞坦克 (Fortress)
- 本体基本固定（speed 0.08），多炮塔齐射
- 新增2-3个浮游护盾卫星环绕旋转，每个独立HP（40-60）
- 卫星可挡子弹，打掉后不恢复
- P2可刷新一波新卫星或卫星爆炸时释放小型弹幕
- 外观：六边形浮游盾板，绕要塞旋转

### 虚空坦克 (Void)
- P1 引力洪流：单一定向炮管正面扇形射出
- P2 黑洞撕裂：从中心引力核心（亮紫色漩涡）360°向四周爆发，不经过炮管
- 外观：中心显著发光奇点 + 一个小型定向炮管 + 多层吸积环
- 逻辑：定向攻击走炮管，全屏爆发走核心，互不矛盾

### 风暴坦克 (Storm)
- 取消传统炮管，电弧从两个特斯拉线圈顶端直接射出
- P1 电弧狩猎：线圈间产生电弧链，向玩家方向释放
- P2 雷霆天幕：从天空标记位置降下落雷
- 外观：无炮管，双线圈+电弧纹路+球形闪电

### 观星者坦克 (Observer)
- 设计：移动观测平台，非传统坦克
- 无炮管，改为大型旋转雷达/扫描碟盘 + 天线阵列 + 激光指示器
- P1 扫描标记：碟盘发射扇形扫描波束，被扫到的玩家被标记
- P2 轨道审判：碟盘竖起朝上→瞄准激光→从天降光束轰炸
- 配色：白蓝（observatory阵营），流线型平台

### 废铁巨像 (Scrap Colossus)
- 不对称外观：左边巨型废铁拳/链球，右边拼装炮管
- 补丁、焊缝、不同颜色装甲板拼接痕迹
- P1：正面散射废铁碎片（不规则扇形）
- P2：链球砸地+弹片飞溅
- 配色：锈红+铁灰+暗橙

### 雷霆执政官 (Thunder Archon)
- 浮空型，不贴地，速度0.75-0.8（最快Boss）
- 对称设计，背后雷电羽翼（电弧翅膀），头顶光环旋转
- 弹幕从光环/羽翼射出，无传统炮管
- P1 雷电裁决：羽翼展开，扇形电弧扫射
- P2 天罚：光环升起，全场随机落雷+追踪闪电球
- 配色：金+白+电蓝，神圣威严

## 炮台转速差异化（全体坦克）

| 阵营/类型 | 转速 | 说明 |
|-----------|------|------|
| observatory（观星台）| 最快 | 精准扫描，炮台如激光瞄准 |
| storm_cloister（雷霆修会）| 快 | 电击反应快 |
| void_cult（虚空教派）| 中快 | 不太靠物理 |
| moon_arsenal（月面兵工厂）| 中 | 标准军事 |
| ash_church（灰域教会）| 慢 | 重甲信仰型 |
| graveyard（残骸群）| 最慢 | 废铁拼装，转不动 |

玩家坦克也按类型差异化转速，狙击最快、广域最慢。

### 玩家坦克转速（按机型）
| 机型 | 转速 |
|------|------|
| 狙击、红枪 | 最快 |
| 追踪、星仪 | 快 |
| 集中、斩魂 | 中快 |
| 扩散、爆裂 | 中 |
| 广域、境界 | 慢 |
