# Triage Labels

本项目使用本地 Markdown issue，因此标签写在 issue 文件内即可。

## 标准标签

- `needs-triage`：需要判断是否要做
- `needs-info`：信息不足，需要补充需求或复现方式
- `ready-for-agent`：已经足够清楚，Codex 可以执行
- `ready-for-human`：需要用户试玩、审美判断或设计取舍
- `wontfix`：不做

## 常用领域标签

- `gameplay`
- `boss`
- `enemy-ai`
- `ui`
- `audio`
- `performance`
- `test`
- `architecture`
- `docs`

## 优先级

- `P0`：阻塞启动或严重崩溃
- `P1`：核心体验问题
- `P2`：重要优化
- `P3`：锦上添花
