# Issue Tracker

本项目默认使用本地 Markdown issue，而不是 GitHub Issues。

## 位置

```text
docs/issues/
```

## 命名

```text
0001-short-title.md
0002-short-title.md
```

## 每个 issue 应包含

- 背景
- 目标
- 范围
- 不做什么
- 涉及文件
- 实现步骤
- 验收标准
- 测试命令
- 状态

## 状态

- `todo`
- `in-progress`
- `review`
- `done`
- `blocked`

## 何时同步到 GitHub

当任务需要发布版本、跨设备协作或记录公开路线时，再把本地 issue 整理到 GitHub。
