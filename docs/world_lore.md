# 幻月战记 世界观档案源稿

> 本文件是图鉴 hover 文案的源稿。`index.html` 内会嵌入同名条目，用于游戏内展示。

## 世界观基调

月亮碎裂之后，夜空不再提供潮汐，只提供命令。人类把陨落的月核称为“月光石”，机装研究室则把它切成可装配的模块，塞进坦克、祭坛、城防和士兵的脊椎里。圣城用祈祷掩埋故障，灰域用残骸喂养引擎；而战场上的每一次升级，都是在向某个更古老的协议借债。

## 道具档案

- 加强履带：灰域运输队的遗物，履带内侧刻着“不要回头”。装上它的人通常真的没有回头。
- 电磁炮：第七观测站用来击穿月壳样本的试验炮。后来样本醒了，炮也被送上前线。
- 反弹弹：圣城钟楼坍塌后回收的相位合金。弹道会记住墙壁，如同记住一次失败的祈祷。
- 能量护盾：机装研究室称它为“短时赦免”。护盾亮起时，驾驶舱里能听见很远处的钟声。
- 急速连射：过热阀门被故意拆除后的产物。它不让武器冷静，也不让驾驶员冷静。
- 维修工具：旧时代工程兵留下的手册残页，夹着一枚干枯的月白花。修复装甲，也修复一点点胆量。
- 冰冻弹：来自北方冷却塔的禁运弹种。它冻结的不是金属，而是敌方装置里那一瞬间的“命令”。
- 散射炮：群星修会早期的防空方案。没有一发子弹被赋予姓名，所以它们一起抵达。
- 磁铁：矿区孩子用月光石碎屑做成的玩具。长大后，玩具被军方重新命名为回收协议。
- 穿甲弹：祈械外壳太厚，普通弹药只会留下火花。穿甲弹的尖端封存着一段低声咏唱。
- 生命汲取：红色模块总是被单独封箱。说明书说它吸收热量，老兵说它吸收遗憾。
- 双倍积分：战术终端的结算插件。它让每一次击毁都更有价值，也更像一笔无法注销的账。
- 巨型子弹：将月核碎片粗暴压铸后的弹体。它飞得不快，却像一座小型审判庭。
- 爆炸弹：灰域爆破队的签名武器。爆光散开时，能短暂照亮地面下埋藏的城市街牌。
- 光学迷彩：不是隐形，而是让敌人的索敌协议忘记你。被遗忘太久的人会开始怀疑自己是否还活着。
- 荆棘护甲：圣城外环的殉爆装甲。它相信伤害应当被归还，哪怕归还得并不精确。
- 火力全开：解除安全栓后的红线模式。研究员称它为效率，驾驶员称它为把明天提前烧掉。
- 时间减缓：观测站的失败钟摆。它不能改变时间，只能让敌人的子弹在一瞬间想起重力。
- 黄金时刻：月光石粉尘被高温点燃后的短暂丰收。所有仪表都会亮成金色，像末日前的庆典。

## 精英敌人档案

- 重装坦克：圣城正门的旧守卫，装甲层比墓碑还厚。它们不追击，只把战线向前推。
- 狙击坦克：观测站失联前发送的最后一种坐标兵器。它开火前会停顿，像在确认你是否值得被记录。
- 疾风坦克：灰域风暴里的侦察机装，轻得像一枚弹壳。它的履带声通常晚于炮火抵达。
- 火焰坦克：焚化区的巡逻单元，把净化和燃烧写进同一个函数。它不憎恨生命，只憎恨潮湿。
- 召唤坦克：移动中继塔，腹部装着未完成的生产祈文。每次呼叫援军，车体都会短暂像祭坛一样发亮。
- 隐身坦克：光学迷彩的军用原型，驾驶舱早已空置。雷达显示它不存在，残骸却证明它来过。
- 分裂坦克：自修复程序被月核污染后的产物。击毁它只是在告诉它，应该以更小的形态继续战斗。
- 再生坦克：机装研究室的“永续样机”。它把伤口当成接口，把时间当成备用零件。
- 激光坦克：圣城塔顶拆下的裁决镜阵。光束扫过时，地面会留下像经文一样整齐的焦痕。
- 地雷坦克：灰域布雷队的无人残部。它们播撒的不是地雷，而是未来某一秒的噩耗。
- 护盾坦克：护教军的移动圣龛。护盾展开时，周围弹片会像朝圣者一样改变方向。
- 导弹坦克：末日前的远程火力平台，导航系统被月相噪声磨坏。它仍会追踪目标，只是不再理解“目标”是什么。

## Boss 档案

- 巨兽坦克：破城级攻城机装，曾拖着三座城门走过灰域。二阶段启动时，它会把自己的装甲当作弹药燃烧。
- 幻影坦克：相位试验的幸存者，也是失败者。它的镜像并非幻觉，而是没有死成的其他可能性。
- 要塞坦克：一座被压缩进履带里的移动堡垒。雷区展开时，战场会短暂恢复成它记忆中的城防图。
- 虚空坦克：第七观测站试图用它封存月洞。现在月洞反过来驾驶它，在战场上寻找新的边界。
- 风暴坦克：气象控制塔的核心残骸。它召来的雷并非来自天空，而是来自碎月背面的静电海。

## 融合协议档案

- 黄金磁铁：回收协议与结算插件互相吞并后的产物。它会吸来补给，也会吸来贪婪。
- 超电磁炮：观测炮与穿甲祈文的重叠协议。发射瞬间，炮口会出现一圈微型月蚀。
- 冰火爆裂：冷却塔弹芯被灰域炸药强行唤醒。冰先让敌人停下，火再解释原因。
- 不死荆棘：红色模块与殉爆装甲的禁忌并联。它不保证你活着，只保证敌人也要付账。
- 弹幕风暴：重弹体进入散射阵列后的失控礼花。每一发都像在替某座失守城市回信。

## 成就档案

- 首次击杀：档案里称它为“第一次回声”。每个驾驶员都从这里开始确认，炮火真的会改变世界。
- 百发百中：观测员在弹孔之间画出细线，像一张临时星图。没有一颗星属于和平年代。
- 坦克杀手：灰域广播会把这类战绩读三遍。不是为了庆祝，而是提醒幸存者还有人活着。
- 战斗老兵：老兵的编号不会写在墓碑上，只写在维修清单里。因为他们总是先修车，再谈伤口。
- 生存专家：第五关之后，驾驶舱里的空气会变得很薄。能继续呼吸，本身就是一种技术。
- 顽强战士：第十关的记录被称为“拒绝撤退”。圣城从不承认这是勇气，只承认这是资源消耗。
- 初露锋芒：第一次高分会被终端存入金色缓存。研究室说那不是奖励，是继续观察的理由。
- 高分玩家：分数越高，战术终端越安静。它已经不需要鼓励你，只需要统计你。
- 积分之王：王冠不是戴在头上的，而是压在履带下的。它越闪亮，战场越黑。
- 硬核玩家：困难模式会关闭许多保护协议。剩下的那些，也只是礼貌地延迟失败。
- 无伤过关：弹片擦过装甲却没有留下痕迹。机装研究室把这种偶然称为“神圣偏差”。
- 扩散大师：扩散弹幕像一把打开的扇。灰域孩子说，那是坦克在替月亮撒花。
- 集中火力：集中型不相信祈祷，只相信一条直线。直线尽头，通常有人来不及后悔。
- 广域压制：广域火力会把战场切成扇形沉默区。敌人不是被击毁，是被命令不得靠近。
- 爆裂艺术家：爆裂型驾驶员总说爆炸也有构图。记录员没有反驳，只把废墟拍了下来。
- 致命狙击：狙击型的每次命中都像一次签名。被签上的目标，不再需要名字。
- 追踪猎手：追踪弹会在废城间绕行，像有自己的记忆。它们迟到，但从不失约。
- 连击大师：连击数字升高时，终端会短暂发热。有人说那是月光石在兴奋。
- 精英猎手：每个精英单位都有独立葬送协议。猎手的工作，是让协议来不及启动。
- 闪电通关：三分钟内穿过五波战线，像把战场撕开一道口子。风会先一步逃出去。
- 道具收藏家：收集模块的人常被误认为贪婪。其实他们只是知道，下一秒可能什么都缺。
- 排雷专家：未触发的地雷也会被记录。灰域相信，真正的好运应该写进军功章里。
- 无尽征途：第十五波之后，地图边缘开始重复。不是你在前进，是战场不肯结束。
- 完美通关：没有受伤的记录最不可信。因为每个完美故事，都像被谁偷偷修过。
- 战场显圣：一万分时，终端会显示一行旧时代乱码。研究室翻译成：继续。
- 月面王冠：两万分记录会被上传到碎月链路。没有人知道链路另一端是否还有接收者。
- 灰域远征：第二十波的幸存者会看见更远的雾。雾里不是终点，只是另一段战线。
- 碎月行军：第二十五波被称为“长夜中段”。能走到这里的人，已经不再问黎明在哪。
- 火线礼赞：三十五连击像一段急促祷词。每个音节都由炮口发出。
- 弹幕圣歌：五十连击会让弹道形成短暂合唱。那不是音乐，是幸存者的心跳被放大了。
- 精英清算者：二十五个精英编号被划掉后，清算者会获得新的空白名单。名单很长。
- 模块掠夺者：四十次拾取会让机体像拼接圣像。每一块零件都来自不同的灾难。
- 月光石库管：五百枚月光石足够点亮一座小礼拜堂。也足够把它再次炸平。
- 碎月银行：一千枚月光石会吸引研究室的注意。注意，有时比敌人更危险。
- 机装全谱系：六种机体列入同一名册时，终端会生成一份不存在的部队番号。
- 整备学徒：十次强化后，驾驶员开始听懂维修员的沉默。那是另一种战场语言。
- 机装技师：三十次强化不是熟练，而是妥协。每一次拧紧螺栓，都在放弃一点旧人类。
- 初次进化：第一次进化会让机体短暂失声。仿佛有什么新东西在内部学会呼吸。
- 六相开花：六次进化记录合并时，屏幕上会出现花的形状。研究室立刻把它归类为武器。
- 日课清算：每日目标来自一台早已离线的调度机。它仍准时发布命令，像世界还完整。
- 梦魇存活者：梦魇难度的第五关没有祝贺语。只有一段静默，长得像追悼。
- 首领目击者：第一次看见首领时，雷达会慢半拍。机器也需要一点时间理解恐惧。
- 破城记录：第十二波之后，Boss不再像敌人，更像灾害。破城者学会向灾害开火。
- 无伤连祷：十五连击且未受伤，像在弹雨中完成一段仪式。圣城拒绝承认这不是神迹。
- 长夜尽头：第三十波之后，夜色不再变深。因为记录员已经找不到比“长夜”更黑的词。
- 碎月铭刻：三万分会被刻入碎月链路的冷备份。即使终端烧毁，这串数字也会继续发光。
- 弹道圣裁：七十五连击像一次审判，弹道在空中排成圣裁纹章。敌人只来得及听见结论。
- 肃清令执行者：四十个精英信标熄灭后，灰域会短暂安静。那不是和平，只是敌方在重新点名。
- 首次融合协议：第一次融合协议启动时，机体会发出不属于任何工厂的钟声。研究室称其为可控异常。
