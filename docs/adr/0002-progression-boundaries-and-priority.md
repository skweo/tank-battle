# ADR 0002: Progression Boundaries And Priority

Date: 2026-06-21

## Status

Accepted

## Context

The game now has multiple meta-progression systems: the protocol tree, the lab, and the planned sortie protocol slots. If the lab gains too many global upgrades before the protocol tree is improved, the protocol tree becomes less meaningful and the progression systems compete for the same design space.

## Decision

Keep the protocol tree as the global long-term progression system, keep the lab as the single-tank buildcraft system, and use sortie protocols as per-run challenge factors selected after choosing a tank. Optimize in this order: rebuild the protocol tree UI first, deepen the protocol tree second, then return to lab gameplay upgrades such as universal parts, signature parts, part tuning, and overload.

## Consequences

Lab gameplay upgrades are intentionally paused until the protocol tree has a clearer UI and deeper global progression identity. Future lab upgrades should avoid replacing protocol-tree value; they should focus on tank-specific playstyle choices and mission-gated signature parts.
