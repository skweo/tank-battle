# 0018 Boss body art design slice

## Goal

Improve Boss identity through body art, silhouette, chassis, armor, and weapon hardware instead of generic effects.

## Scope

- `TRP`: low mine-layer chassis, side mine racks, rear deployment chute, hazard braces.
- `WEV`: mobile sanctum loom, frame posts, thread anchors, spindles, summon gates.
- `SCT`: cathedral bunker body, stained-glass armor, physical shield hardware.
- `ORB`: braced railgun platform, stabilizer legs, twin rails, breech block, heat fins.
- `ARB`: hovering tribunal seat, rigid storm vanes, coil pylons, judgment crest.
- `SND`: buried sand-crawler chassis, drill nose, worm pods, intake vents.
- `GRV`: ballast machine, chain reels, anchor flukes, gravity core housing.
- `HYD`: segmented bio-tank body, independent head cannons, armor ribs.
- `AST`: observatory chassis, physical armillary supports, tick-mark rings, telescope barrel.

## Rules

- No gameplay value changes.
- No generic ordinary-enemy overlays.
- Boss identity should be readable from the body shape before effects.
- Effects may support the existing telegraph, but should not carry the design alone.

## Acceptance

- Selected Bosses have distinct chassis and hardware silhouettes.
- Existing warning, AI, and combat balance behavior remains unchanged.
- Smoke tests include a draw pass for the selected Boss body-art slice.
