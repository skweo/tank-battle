# 0019 修正难度解锁提示

## 目标

让锁定难度显示正确的前置难度，例如“简单模式获得2800分解锁普通”。

## 范围

- 修正首页难度按钮中的解锁提示文案。
- 为五档难度的顺序解锁关系增加冒烟测试。

## 不做什么

- 不调整解锁分数。
- 不修改难度解锁逻辑。
- 不改动其他界面或玩法。

## 涉及文件

- `scripts/game.js`
- `tests/smoke.js`

## 验收标准

- 普通、困难、极限、梦魇分别引用简单、普通、困难、极限模式作为前置难度。
- 所有冒烟测试通过。

## 测试命令

```powershell
node tests/smoke.js
node --check scripts/game.js
```
